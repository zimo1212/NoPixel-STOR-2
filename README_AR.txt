NoPixel Store - موقع المتجر

التشغيل:
1) فك ضغط NoPixel_Store.zip.
2) افتح index.html لمعاينة الموقع.
3) ارفع كامل المجلد كما هو إلى استضافة مواقع ثابتة.

روابط Discord:
تم تحديث روابط Discord إلى:
https://discord.gg/kMkv3NTD2t

تغيير المنتجات:
1) ضع الصور داخل assets/products/ في المجلد المناسب:
   - cars       للسيارات
   - houses     للمنازل والعقارات
   - buildings  للمباني
   - memberships للعضويات
   - other      للمنتجات الأخرى
2) افتح data/products.js بمحرر مثل VS Code.
3) انسخ قالب المنتج التالي وأضفه داخل المصفوفة products:

{
  name: "فيلا فاخرة",
  category: "houses",
  price: "5000 دج",
  image: "assets/products/houses/villa1.jpg",
  description: "فيلا مع مسبح وموقف سيارات"
}

4) ضع صورة الفيلا باسم villa1.jpg داخل assets/products/houses/.
5) احفظ الملف وحدّث صفحة المتجر في المتصفح.

القيم المسموحة لـ category:
cars, houses, buildings, memberships, other

طرق الدفع:
تمت إضافة CCP وPayPal وBaridiMob في المتجر.
لتعديل بيانات الدفع، افتح data/payments.js واستبدل النصوص الإرشادية ببيانات الدفع التي تريد عرضها للزبائن.
لا تضع كلمات مرور أو رموز تحقق أو معلومات دخول في هذا الملف.

مهم بخصوص الدفع:
الموقع يعرض طرق الدفع وتعليماتها فقط. لا ينفذ تحويلاً مالياً أو يتحقق تلقائياً من الدفع.
تأكيد الطلب يتم يدوياً عبر Discord بعد إرسال إثبات الدفع.
لإنشاء دفع إلكتروني آلي وآمن، يلزم ربط بوابة دفع/خادم خلفي وحساب تاجر مناسب.

الملفات المهمة:
- store.html: صفحة المتجر.
- store.js: عرض المنتجات والفلترة حسب القسم.
- data/products.js: قائمة المنتجات التي تعدلها أنت.
- data/payments.js: أسماء طرق الدفع وتفاصيلها.
- assets/products/: ضع صور منتجاتك هنا.
- style.css: التصميم والألوان.
