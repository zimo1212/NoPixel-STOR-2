NoPixel Store - أداة إضافة الصور والمنتجات تلقائياً
====================================================

المتطلبات:
- Windows 10 أو Windows 11
- Python 3 مثبت (إذا لم يعمل الملف بالنقر المزدوج)

طريقة التشغيل:
1. فك ضغط NoPixel_Image_Importer.zip.
2. افتح NoPixel_Image_Importer.py بالنقر المزدوج.
   أو افتح CMD داخل المجلد واكتب:
   python NoPixel_Image_Importer.py
3. في "مجلد الصور" اختر المجلد الذي يحتوي الصور (مثل مجلد buildings الذي فيه 12 صورة).
4. في "مجلد المتجر" اختر المجلد الرئيسي للموقع، الذي بداخله مجلد data ومجلد assets.
   مثال: اختر NoPixel_Store وليس NoPixel_Store/data.
5. اختر نوع المنتجات: buildings أو houses أو cars أو memberships أو other.
6. اكتب السعر والوصف الافتراضيين، ويمكنك ترك بادئة الاسم فارغة.
7. اضغط "إضافة الصور إلى المتجر تلقائياً".

ماذا تفعل الأداة؟
- تقرأ الصور مباشرة من المجلد المختار: JPG / JPEG / PNG / WEBP / GIF.
- تنسخ الصور إلى assets/products/الفئة المختارة.
- تضيف منتجاً لكل صورة في data/products.js.
- تستخدم اسم الملف كاسم المنتج (مثلاً building1.jpg يصبح building1).
- تتخطى الصور التي سبق تسجيل مسارها في products.js.
- تنشئ نسخة احتياطية باسم products.js.backup قبل أول تعديل.

مهم:
- الأداة تتعامل مع ملف JavaScript الذي يحتوي:
  const products = [ ... ];
- ضع الصور مباشرة داخل مجلد الصور المختار، وليس داخل مجلدات فرعية.
- بعد الاستيراد حدّث صفحة المتجر. لا تتضمن الأداة الدفع أو رفع الموقع للإنترنت.
